# Lesson 1: Team trails — starter

Use Java 18 or later. This program compiles before the TODOs are completed;
its initial output is a starting state, not the finished result described below.

## Open and run in jGRASP

1. Extract the entire lab folder to a writable location.
2. Open `TeamTrails.gpj` in jGRASP, then open `TeamTrails.java` from the project.
3. Compile and run the Java file. The project uses the local `jkarel.jar`.
   If a classroom jGRASP version does not pick up that setting, select
   **Settings → PATH/CLASSPATH → Project → CLASSPATH**, and add this folder's
   `jkarel.jar`. Remove any conflicting older JKarel entry.
4. Complete the TODOs, rerun, and compare the result with the lesson.

## Before you edit

The boundaries and divider are supplied. Both robots walk east, but keep their five beepers and their default appearance until you add colors and drops.

## Your work

1. Set the two robot colors and add the missing drops in the loop.
2. Produce red and blue five-beeper trails on rows 2 and 4, columns 2 through 6.
3. Then change a color mid-trail and investigate two drops on one cell.

The corresponding lesson is `01-team-trails.md` in the curriculum packet.
The complete `TeamTrails.java` listing in the packet appendix is a reference.
Keep your edits in this starter folder; the complete example is separate.
