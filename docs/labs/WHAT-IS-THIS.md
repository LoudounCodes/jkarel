# What is this?

LoudounCodes JKarel is a modernization of the original FCPS Karel library. It uses
a more fluent interface, targets Java 18, and provides internals that can serve
as teaching examples in more advanced Java courses. Students can still work with
the familiar robot actions while learning how the library represents an arena,
handles events, and draws its objects.

This curriculum teaches the updated interface, the new capabilities, and the
Java concepts needed to use them. It starts with the differences from the older
library, then introduces features through short lessons and complete, commented
example programs. Later lessons explore interfaces, inheritance, and custom
rendering.

If you or your students already know Karel or an earlier version of JKarel and
want to build game-like experiences, these lessons are for you. Projects can
include walls and doors that are added or removed during play, robots and
beepers in different colors, and game rules that react to events such as moves
and beeper pickups. Choose the lessons that support the project you want to
build.
